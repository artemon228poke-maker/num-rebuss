# num-rebuss — решатель числовых ребусов

Лабораторная работа №2. Реализация на языке C.

## Что такое числовой ребус

Головоломка, в которой цифры заменены буквами. Пример:

```

SEND + MORE = MONEY
9567 + 1085 = 10652

```

## Требования (из ТЗ)

1. Все буквы в верхнем регистре.
2. Каждой букве — ровно одна цифра, разным буквам — разные цифры.
3. Ведущие нули запрещены.
4. Основная операция — сложение `+`. (Опционально — `-`, `*`, `/`.)
5. Слагаемых слева от 2 до 7.
6. Входные данные гарантированно имеют хотя бы одно решение.

## Сборка

```bash
make
```

Соберёт две программы:

- `rebus` — основной решатель,
- `bench` — бенчмарк (будет добавлен позже).

## Запуск

Один ребус:

```
echo "SEND + MORE = MONEY" | ./rebus
```

Несколько ребусов из файла:

```
./rebus < tests/cases.txt
```
